## 简介

I Have ADHD 是一款 Claude Code 技能（可作为插件安装），用于改变编程智能体的回复方式。它会促使智能体把答案放在最前面、保持输出便于扫读，而不是用冗长的铺垫把结论埋起来，非常适合 ADHD 读者或任何希望开门见山的人。

## 主要特性

- 强制智能体结论前置，不再把答案淹没在解释之中
- 减少回复中的填充、含糊措辞和冗长铺垫
- 以 Claude Code 技能/插件形式提供，可按会话启用
- 对 ADHD 友好的格式，优先保证可扫读性和直接性

## 使用场景

- 在开发过程中让编程智能体的输出更易快速扫读
- 帮助神经多样性用户无需阅读大量铺垫即可直达答案
- 在多次编程会话中统一简洁、结论前置的回复风格

## 技术特点

- 以 Claude Code 技能形式分发，支持插件式安装
- 兼容支持 Agent Skills 规范的智能体框架
- 轻量级指令式技能，无运行时依赖
