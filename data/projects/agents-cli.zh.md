## 简介

Agents CLI 是 Google 开源的命令行工具与技能包，可将任意编程助手升级为在 Google Cloud 上构建、评测、治理和部署 AI Agent 的专家。它与 Agent Development Kit（ADK）及 Gemini 生态集成，覆盖 Agent 从创建到生产部署的完整生命周期。

## 主要特性

- CLI 加技能包，兼容任意编程助手。
- 覆盖 Agent 创建、评测、治理和部署工作流。
- 基于 Google ADK 与 Gemini 企业 Agent 平台构建。
- 官方文档站点 google.github.io/agents-cli 提供指南。

## 使用场景

- 在终端中构建并部署基于 ADK 的 Google Cloud Agent。
- 生产上线前对 Agent 进行评测与治理。
- 跨编程助手标准化 Agent 开发工作流。

## 技术特点

- 以 CLI 加 Agent 技能包形式增强任意编程助手，而非绑定特定 IDE 插件。
- 单一工具覆盖 Agent 完整生命周期：基于 ADK 脚手架创建、评测、治理、部署到 Google Cloud。
- 技能包让 Agent 开发专业知识可跨 Claude Code、Gemini 等助手复用。
- 基于 Agent Development Kit 与 Gemini 企业 Agent 平台构建。
