## Overview

Rowboat is an open-source desktop AI coworker with a memory of your work. It indexes your activity into a living knowledge graph and uses that context to get work done on your machine, with built-in surfaces for collaborating with AI: email client, notes, browser, code mode, meeting note taker, and project workspaces. Available for Mac, Windows, and Linux.

## Key Features

- Living knowledge graph built from your ongoing work.
- Built-in work surfaces: email, notes, browser, code mode, meeting notes, workspaces.
- Long-term memory that grounds the coworker's actions.
- Cross-platform desktop app (Mac/Windows/Linux).

## Use Cases

- Personal AI assistant that remembers your projects and context.
- Automate email, notes, and meeting follow-ups with agent memory.
- Local-first AI coworker for daily productivity.

## Technical Details

- Local-first desktop app; work activity is continuously indexed into a living knowledge graph rather than flat chat history.
- Graph memory grounds every action — email drafts and code generation draw on indexed project context.
- Built-in work surfaces (email, notes, browser, code mode, meeting notes, workspaces) act directly on the machine instead of only chatting.
- Supports apps-to-code flows: build small apps from the workspaces and iterate in code mode.
