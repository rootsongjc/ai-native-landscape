WebsiteBench evaluates agents that explore a reference website through a browser and reconstruct its frontend and backend. It uses native Harbor task directories with a candidate compile/runtime contract and a separate no-network verifier.

The public code is licensed under Apache-2.0. Complete task and reference artifacts follow the linked Hugging Face access process; the code license does not establish redistribution rights for reference content.
